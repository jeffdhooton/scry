The initial draft repeated five scenario templates and was rejected before provider inference. The revised corpus contains 20 distinct scenario families, 100 claims, and 30 sealed claims in six separate scenario families. Histories are substantive earlier evidence, not padding. An independent agent reviewed all 100 claims before provider inference; this is agent review, not a claim of human adjudication.

Reference labels consider all eligible direct sources at target time. A compact arm can therefore miss support that retrieval provides: these are legitimate false negatives against the fixed source-truth reference. Derived summaries alone cannot support claims. Durability is conditional on accuracy. The diagnostic 0.5 cutoff has no admission or retention authority.
